# Python Basic Assignment

A beginner-friendly Python project demonstrating fundamental Python concepts such as variables, functions, `if / elif / else` statements, `while` and `for` loops, dictionaries, user input, file handling (`open()`, `write()`, `read()`), basic error handling (`try / except`), and code comments.

---

## Assignment Topics

1. **Menu-driven Calculator** (`calculator.py`)
   Demonstrates interactive menu loops, function definitions (`add`, `subtract`, `multiply`, `divide`), conditional statements, arithmetic operations, and handling division by zero.

2. **Grade Checker** (`grade_checker.py`)
   Demonstrates numerical user input processing, grade evaluation logic using `if / elif / else` branching, and score range verification.

3. **Student Grades Dictionary** (`student_grades.py`)
   Demonstrates dictionary state operations (`add`, `update`, `lookup`), iterating over dictionary items, menu looping, and conditional existence checks (`if name in student_grades`).

4. **Write to a File** (`file_write.py`)
   Demonstrates file handling using `with open(...) as file:` context management in write mode (`'w'`), creating directories, and writing string content using `file.write()`.

5. **Read from a File** (`file_read.py`)
   Demonstrates reading file contents using `with open(...) as file:` context management in read mode (`'r'`), verifying file existence, and extracting content with `file.read()`.

---

## How to Run

Navigate to the project directory:

```bash
cd python_basic_assignment
```

Run each script individually using Python:

### 1. Menu-driven Calculator
```bash
python calculator.py
```

### 2. Grade Checker
```bash
python grade_checker.py
```

### 3. Student Grades
```bash
python student_grades.py
```

### 4. Write to a File
```bash
python file_write.py
```

### 5. Read from a File
```bash
python file_read.py
```
